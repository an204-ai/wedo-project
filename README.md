# WeDo - Ứng dụng Quản lý Công việc

**WeDo** là ứng dụng quản lý công việc (Task Management) full-stack được xây dựng với React và Node.js, giúp người dùng dễ dàng theo dõi, sắp xếp và hoàn thành công việc hàng ngày.

---

## 🛠️ Công nghệ sử dụng

- **Frontend**: React 19, Vite, Tailwind CSS v4, Lucide Icons, Axios.
- **Backend**: Node.js, Express.js, MongoDB (Mongoose), Dotenv.

---

## 📁 Cấu trúc dự án

```text
wedo/
├── backend/          # RESTful API server (Express + MongoDB)
├── frontend/         # Giao diện người dùng (React + Vite)
└── README.md
```

---

## 🚀 Hướng dẫn Cài đặt & Khởi chạy

### 1. Khởi chạy Backend

```bash
cd backend
npm install
npm run dev
```

*Server mặc định chạy tại `http://localhost:3000`*

### 2. Khởi chạy Frontend

```bash
cd frontend
npm install
npm run dev
```

*Ứng dụng Web mặc định chạy tại `http://localhost:5173`*
